Besprited

A free and open source program for creating and animating 2D sprites. Real-time previews, onion skinning, tiled drawing and pixel-precise tools, built for people who want a fast, opinionated editor.

Download latest release View on GitHub

Features

Real-time previews

Watch your animations play back live as you draw them, no extra steps needed.

Onion skinning

See surrounding frames while you work to keep motion smooth and consistent.

Multi-sprite editing

Work on several sprites at once without losing track of the rest of your project.

Palettes

Use ready-to-go palettes or build your own from scratch.

Layers & frames

Sprites are composed of both layers and frames for full control over your art.

Tiled drawing mode

Draw patterns and textures with the canvas tiling as you go.

Pixel-precise tools

Filled contour, polygon, shading mode, and other tools built for pixel art.

Format support

Several file types are supported for your sprites and animations.

About

Besprited traces back to Aseprite, which moved from a GPLv2 license to a proprietary one in 2016. LibreSprite was created in response, forking the last GPLv2 version to keep it free and open source.

In 2026, Nidrax forked the project under the Veritaware organization to build an opinionated version of the editor, independent of LibreSprite's design decisions, with a faster and more experimental development cycle. That's how Besprited was born.
