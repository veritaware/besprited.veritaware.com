Roadmap

Milestone 1.26.12 — December 2026

This milestone mostly focuses on bugfixes, code cleanup and refactoring, solving hidden technical debts inherited from LibreSprite/Aseprite and preparing the codebase for bigger upcoming features. The security and refactoring audit is already complete.

Security & refactoring audit

Static-analysis findings, hardened file loaders and extension installer, undo fixes, leak fixes and a round of command and filter refactors.

Done · #219, #120, #214

SDL3 migration

The rendering and windowing backend is being upgraded from SDL2 to SDL3.

#73

Layer groups

Organise the layer stack by grouping related layers together, delivered in phases: layer tree indexing, undo and API support, crash recovery, timeline tree rows and .ase persistence.

#84, #275, #276, #277, #278, #279, #281

Catppuccin theme

A first-party theme built around the Catppuccin palette.

#66

Better .ase compatibility

Preserve more of the Aseprite file format when saving and loading: color profiles, cel positioning, tag options, slices, user data and more.

#189, #190, #191, #192, #193, #194, #195, #196, #197, #307

OpenRaster support

Open and save .ora files, built on new ZIP and in-memory PNG groundwork.

#299, #300

Milestone 1.27.03 — March 2027

A round of Aseprite-parity improvements and broader file-format support. A few highlights:

More format support

Import layered PSD, Krita, GIMP XCF and Resprite files on a shared foundation, plus APNG and TIFF support.

#112, #113, #114, #209, #289, #117, #152

Dark/Light mode hinting

The application would recognize if to use a light or a dark theme based on OS settings.

#38

Open multiple files at once

Select and open several documents in a single step.

#150

Select and edit multiple layers

Apply edits and transforms across several selected layers at once.

#141

Paste as new layer

Drop clipboard contents straight onto a fresh layer.

#137

Draggable canvas size borders

Resize the canvas by dragging its edges directly.

#151

Numeric entry for sliders

Type exact values into sliders instead of dragging.

#52

Internationalization rework

Gettext-style plurals, composable phrases, explicit translation markers and extraction tooling with CI checks.

#284, #286, #287, #288

Milestone 1.27.06 — June 2027

The next big feature release. A few highlights from the list:

Text tool

Edit text directly on the document canvas instead of using a separate input dialog.

#26

Gradient tool

Fill selections and shapes with automatically dithered colour gradients.

#10

Tiled integration

Edit tilesets in Besprited and see them update live in Tiled, and preview TMX/TMJ maps right inside Besprited.

#305, #306

Skew/Shear selection

Distort selections with skew and shear transforms.

#122

Hue/Saturation adjustment

Recolour sprites non-destructively with HSL adjustments.

#39

Custom pixel aspect ratio

Work with non-square pixels for a wider range of art styles.

#15

Layer thumbnails

Preview each layer's contents right in the layer list.

#136

Custom UI fonts

Load your own fonts for the application interface.

#85
